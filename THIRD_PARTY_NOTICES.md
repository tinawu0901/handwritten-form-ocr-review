# Third party components

This project uses third-party libraries and pretrained models. They are not authored by this project, and their licenses and model-specific terms remain applicable.

- [OpenCV](https://github.com/opencv/opencv): image processing and grid geometry.
- [PaddleOCR](https://github.com/PaddlePaddle/PaddleOCR) and [PaddlePaddle](https://github.com/PaddlePaddle/Paddle): text detection and recognition.
- [Flask](https://github.com/pallets/flask): local review server.
- [openpyxl](https://openpyxl.readthedocs.io/): Excel workbook creation.
- [NumPy](https://github.com/numpy/numpy): numerical image and geometry operations.
- Optional experiments use [PyTorch](https://github.com/pytorch/pytorch), [Transformers](https://github.com/huggingface/transformers) and [Microsoft TrOCR](https://huggingface.co/microsoft/trocr-base-handwritten).

Model weights and external training-source checkouts are not included in this distribution. Consult the installed dependency versions and upstream notices before redistributing third-party code or weights. This file records component attribution; it does not grant a license for this project's own source.
